# 1단계 내부 분석 체크리스트 (PPOK_PHOTOREAL v3.1)

이 체크리스트는 이미지를 보고 JSON 프롬프트를 정확히 구성하기 위한 내부 분석 가이드다. 사용자에게 분석 과정을 나열하지 않고 바로 최종 JSON을 도출한다.

---

## A. 구조 및 천장 리스크 스캔
존재하는 항목만 `structure_lock.critical_details`에 반영한다:
- [ ] **천장 형태**: 우물천장, 단차 트레이 천장, 곡면 코브, 평천장, 노출 콘크리트
- [ ] **천장 기구물**: 3D 실링팬, 트랙 조명 레일, 1way/4way 시스템 에어컨, 다운라이트 타공
- [ ] **벽체 및 개구부**: 라운드 코너, 비직교 사선 벽, 대형 유리 파티션, 히든 도어
- [ ] **고정 가구**: 붙박이 수납장, 리셉션 데스크, 플로팅 세면대, 빌트인 진열장
- [ ] **창호 및 블라인드**: 슬림 시스템 창호, 수평 베네시안 블라인드, 롤스크린

## B. 조명 색온도 및 조도 분석 (중요)
- [ ] **광원 색온도 판독**:
  - 주광색 (쿨 화이트 / ~6000K)
  - 주백색 / 백색 (뉴트럴 화이트 / ~4000K)
  - 전구색 (따뜻한 웜톤 / ~3000K)
  - 혼합 광원 (예: 기본 4000K + 코브 3000K 웜톤)
- [ ] **조도 레벨 판독**:
  - 밝은 공간 / 표준 조도
  - 어둡고 명암 대비가 강한 공간 (Low-key / Moody)
  - 국소 집중 조명만 켜진 공간
  - ⚠️ **조도가 어두운 경우: 과도하게 밝기를 띄우지 않고 어두운 무드를 그대로 유지하는 노출값 설정**

## C. 표면별 마감재 인벤토리
1. **천장**: 석고보드 페인트 도장 질감, 코브 간접조명 그라디언트, 등기구 베젤
2. **바닥**: 포세린 타일(혼드/매트), 원목/강마루, 에폭시, 카펫
3. **벽체**: 우드 무늬목 패널, 도장 벽체, 템바보드, 석재, 유리 파티션
4. **가구**: 가죽 소파/의자, 사무용 데스크, 패브릭 파티션, 금속 프레임

## D. 제거 대상 스케치업 아티팩트
- 천장/벽체/가구의 검은색 엣지 라인(Profile Lines)
- 평평하고 질감 없는 2D 단색 셰이딩
- 플랫 2D 컷아웃 실링팬 및 단순 검은 선 트랙 조명
- 인위적인 밝기 과다 상승 및 그림자 날림 현상
