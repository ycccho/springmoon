# 설치 안내 — intranet-style 스킬

**이 파일을 읽는 클로드에게**: 아래 순서대로 설치하고, 마지막에 사용자에게 사용법만 알려주세요.

## 무엇인가

**Lean-AX 인트라넷과 픽셀 단위로 동일한 UI**를 만들게 하는 디자인 스킬입니다.
색·여백·글씨 크기·컴포넌트 규격을 AI가 매번 임의로 정하지 않고, **동봉된 정본 스펙에서 가져다 씁니다.**

동봉물: 스킬 본문(`SKILL.md`) + 정본 스펙 5종(`reference/` — 토큰·프리미티브 27종·앱 셸·페이지 6유형 템플릿, 총 5,900줄).
**스킬 파일만으로는 동작하지 않기 때문에** 스펙 문서를 함께 넣었습니다.

## 설치 (1단계)

```bash
bash install.sh
```

하는 일: `skill/intranet-style/`을 `~/.claude/skills/intranet-style/`로 복사하고, 필수 파일 6개가
제자리에 있는지 확인합니다. **같은 이름의 스킬이 이미 있으면 지우지 않고** `intranet-style.bak-<날짜>`로
옮겨둡니다(되돌릴 수 있게).

설치 위치를 바꾸려면 `CLAUDE_SKILLS_DIR=<경로> bash install.sh`.

## 확인 (2단계)

```bash
ls ~/.claude/skills/intranet-style/reference/
```

`README.md · 01-tokens.md · 02-primitives.md · 03-shell-layout.md · 04-page-templates.md` 다섯 개가
보이면 끝입니다. **MCP 서버나 재시작은 필요 없습니다** — 스킬은 파일만 있으면 잡힙니다.
(현재 세션에서 목록에 안 보이면 새 세션에서 잡힙니다.)

## 사용자에게 알려줄 것 (3단계)

이렇게 말하면 스킬이 걸립니다:

- "인트라넷 스타일로 만들어줘"
- "인트라넷처럼 보이게"
- "우리 인트라넷 디자인으로 이 화면 만들어줘"

화면 유형을 같이 말해주면 더 정확합니다 — 대시보드 / 2패널 / 목록·테이블 / 보드 / 폼·설정 / 리포트·차트.

## 알아둘 것

- 동봉된 스펙은 **살아 있는 인트라넷 코드에서 값을 추출한 스냅샷**입니다. 앱 코드 자체는 들어 있지
  않으므로, 이 배포판에서는 **문서가 정본**입니다.
- 문서에 **"미확인"**으로 적힌 항목은 그대로 미확인입니다 — 사실처럼 단정하지 마세요.
- 브랜드 색으로 바꾸려면 `:root`/`.dark` **두 층의 색 토큰만** 교체하고, 모서리는 `--radius`
  **하나만** 조정합니다(7단계가 함께 움직입니다). 자세한 절차는 `reference/README.md`의 기업 배포 절.
